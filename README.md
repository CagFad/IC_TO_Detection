# IC_TO_Detection
Alogorithm to detect initial contact and toe-off for various locomotion tasks. Input from a single axis gyroscope attached to shank is required. 
Algorithm description can be found in the original publication (Fadillioglu et al., 2020).

Fadillioglu, C., Stetter, B. J., Ringhof, S., Krafft, F. C., Sell, S., & Stein, T. (2020). Automated gait event detection for a variety of locomotion tasks using a novel gyroscope-based algorithm. Gait & Posture, 81(June), 102–108. https://doi.org/10.1016/j.gaitpost.2020.06.019
